# ATmosphere Brand Assets

Source brand files for the ATmosphere plugin. Excluded from the plugin build
(`branding/` is listed as `export-ignore` in `.gitattributes`), so nothing here
ships in the WordPress.org zip or GitHub release tarball.

Each asset is provided as both PNG and SVG.

## Logo

Full ATmosphere wordmark (symbol + lettering).

- `ATmosphere_logo-on white` — black mark on a white background
- `ATmosphere_logo-on black` — white mark on a black background
- `ATmosphere_logo-on black-1` — mark on a blue (`#1185FE`) background
- `ATmosphere_logo-transparent` — no background fill

## Symbol

The standalone mark, without the wordmark.

- `ATmosphere_Symbol-on white` — on a white background
- `ATmosphere_Symbol-on black` — on a black background
- `ATmosphere_Symbol-on blue` — on a blue (`#1185FE`) background
- `ATmosphere_Symbol-on gray` — on a gray (`#EDEDED`) background
- `ATmosphere_Symbol-transparent` — no background fill
- `ATmosphere_Symbol-transparent-cut middle` — no background fill, with a gap splitting the mark

## The covers

Promotional banners (PNG only).

- `ATmosphere_Dotorg-plugin-banner 1` / `ATmosphere_Dotorg-plugin-banner 2` — WordPress.org plugin header banners
- `ATmosphere_GitHub-banner` — GitHub repository banner
